# 🔮 Predictor API

The `NodeFDMPredictor` serves as the **inference engine** for the framework.

It loads trained model artifacts (checkpoints and metadata), reconstructs the neural architecture, and performs full trajectory rollouts by integrating the learned dynamics over time.
