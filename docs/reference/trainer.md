# 🏋️ ODETrainer API

The `ODETrainer` class acts as the **high-level orchestrator** for the training pipeline.

It validates the `TrainingConfig`, retrieves the architecture from the registry, initializes the training environment, and manages model checkpoints and metadata artifacts.
